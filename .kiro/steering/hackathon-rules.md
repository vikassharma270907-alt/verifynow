# Hackathon Judging Criteria & Submission Rules

## Mandatory Requirements (Disqualification if Missing)
- Must use Nebius Token Factory or Nebius AI Cloud
- Must integrate at least one NVIDIA open-source model (Nemotron family)
- Public GitHub repo with visible open-source license (MIT)
- YouTube demo video ≤ 3 minutes
- Comprehensive README with setup instructions
- Structured platform feedback on Nebius/NVIDIA stack

## Four Judging Criteria (Equal Weight)
1. **Technological Implementation** — multi-model tier routing, serverless orchestration, deterministic verification, clean reproducible repos
2. **Design** — native workflow integration, "aha moment" in 30s video / 2min app, transparent UI
3. **Potential Impact** — real user validation, quantifiable problem
4. **Quality of the Idea** — closed-loop autonomy, LLM outputs as untrusted claims, domain-specific innovation

## Time-to-Value Benchmarks
- **30 seconds**: demo video must show the core value
- **2 minutes**: live app must deliver core value
- **5 minutes**: repo must spin up locally via docker-compose

## What Judges Penalize
- Single-prompt API wrappers
- Generic chat interfaces
- Mocked/hardcoded responses
- Missing open-source license
- Slow theoretical video intros
- No defined user persona
